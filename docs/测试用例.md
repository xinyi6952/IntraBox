# IntraBox 测试用例文档

本文档说明 IntraBox 的测试方式：**确定性逻辑用自动化测试（`test.bat` 一键跑），交互型功能按手动清单逐项验证。**

## 一、自动化测试（已实现，跑 `test.bat`）

`test.bat` 会构建测试项目 `tests/IntraBox.Tests` 并运行全部 MSTest 用例。当前已覆盖以下确定性逻辑：

| 功能 | 覆盖的用例 | 关键断言 |
|---|---|---|
| JSON 格式化 | 美化/压缩/非法/空输入 | 缩进换行、单行无空格、错误返回 null+信息 |
| SQL 格式化 | 关键字大写/子句换行/AND 行首 | 含 SELECT、FROM、缩进 |
| 哈希 | MD5/SHA256/差异/ToHex | RFC 官方向量（如 MD5("abc")） |
| Base64 | 编码/往返/非法 | 已知值、往返一致、抛异常 |
| 时间戳 | 起点/往返/秒毫秒 | 时间戳 0 = 1970、往返一致 |
| ULID | 长度/字符集/两次不同 | 26 位 Crockford Base32 |
| 模块注册 | 无独立 ULID/GIF 入口 | 仅 idgenerator，无 ulidgen、screengif |
| 文本文件编码 | GBK/UTF-8/带 BOM 往返 | 自动检测编码、写回字节一致 |
| Hosts 文件 | 保存/注释空行/启用切换/改动摘要 | 保留注释空行、未改行原样写回；启用去掉行首空格和 `#` 后空格，禁用只加 `#` 不加空格 |
| 防止睡眠 | 时长解析 | 分钟/小时换算、非法输入报错 |
| 文件整理 | 匹配/目录展开/日期去重/撤销落盘 | 扩展名忽略大小写、{date} 不与当天重复、规则 JSON 不含撤销记录 |
| 设置历史 | 数字兼容/剪贴板条数夹取 | long/double 兼容、超长字符串不入库 |
| 剪贴板图片 | DIB/PNG/Alpha/缩略图/DataObject 写回 | 全 0 Alpha 不黑、24 位 DIB 往返、自顶向下、超限只读头、写回含 PNG+24 位 DIB |
| 命名转换 | 分词/各风格/空输入 | camelCase/snake_case、XMLHttp 拆分 |
| URL 解析 | 各字段/query 解码/hash/非法 | scheme/host/port/path、%E4%BD%A0→你好 |
| Unicode 检查 | ASCII/中文/代理对/编码 | U+0041、U+4E2D、😀=U+1F600、UTF-8/16 |
| SemVer 比较 | 解析/比较/^~范围 | 预发布<正式版、^1.2.3<2.0.0 |
| JSON Schema | 推断/校验/错误 | type/properties/required、缺必填报错 |
| 正则解释 | 转义/锚点/字符类/量词/分组 | \d=数字、[abc]=集合、{2,3}=重复 |
| 编解码 | URL/HTML/Unicode 编解码 | 百分号编码、HTML 实体、\u 转义往返 |
| 行处理 | 拆行/去重/排序/自然序/前后缀 | file2<file10、保序去重 |
| 文本统计 | 字符/词/行/段落/词频 | 忽略大小写词频、空行分段 |
| 文本转 Excel | 分隔符探测/表格解析 | 逗号/制表符、空行跳过、单元格 trim |
| 加解密 | AES/DES 往返、RSA、密钥派生 | 加密解密往返、密文含随机 IV |
| 证书解析 | PEM 解析/格式化 | CN=主体、有效期、指纹 |
| 启动器 | 标题/目录路径匹配/排序/脚本与 URL 校验/树迁移 | 置顶>最近>开头>包含、空查询顺序、按收藏目录路径搜、允许 bat、拒绝 cmd/vbs/ps1 与非 http(s)、已在运行判定、旧分类迁目录、打开方式与程序确认 |

> 确定性逻辑已全部抽出 `Core/*Helper` 并通过 MSTest 用例；仅「进制类转换」在代码中无独立实现而未单独覆盖。剪贴板监听/写回的 UI 与占用重试仍走下方手动清单。

## 二、手动测试清单（交互型功能，需人工点）

以下功能依赖 UI/系统交互，无法自动化，按「操作 → 期望」逐项验证。

### 截图 / 屏幕标尺
- [ ] 全局热键（Ctrl+Alt+A）能唤起，出现全屏遮罩 + 十字光标
- [ ] 框选区域 → 显示工具栏（默认是「移动/选择」光标，非矩形）
- [ ] 画矩形/箭头/文字/马赛克 → 撤销 → 重做（重做能恢复）
- [ ] 钉在桌面后，工具栏仍显示、仍可标注
- [ ] 保存到文件、复制到剪贴板
- [ ] OCR 识别图中文字，结果可选中复制
- [ ] 屏幕标尺：热键或按钮打开 → H/V/R 测量 → 显示像素与厘米

### 文本比对
- [ ] 粘贴左右文本 → 自动出差异（红删绿增）
- [ ] 点合并箭头 → 合并 → 撤销（Ctrl+Z）
- [ ] 上一个/下一个差异 → 到顶/到底时提示不循环
- [ ] 上一个/下一个差异时当前差异块有覆盖色 + 左侧竖条高亮；清空或一侧改文本导致类型不一致后高亮消失
- [ ] 拖文件到左右 → 自动加载并比对；GBK/UTF-8 文件不乱码
- [ ] 文件比对 + 合并后点清空 → 弹保存确认
- [ ] Ctrl+F 搜索条：输入不立即搜；点「查找」或 Enter 才搜；Enter 下一个、Shift+Enter 上一个、Esc 关闭
- [ ] 切换左侧/右侧后点查找，高亮只画在当前侧，旧侧不再残留橙色

### 剪贴板历史
- [ ] 复制文字 → 出现在列表 → 双击或右键写回；复制空内容或纯空白不入库；再复制已有内容时列表仍一条并以最新时间为准
- [ ] 搜索、右键「查看」（窗口内最大化，文本靠顶部）/「写回剪贴板」/「固定」/「删除」（二次确认）/「清空非固定」；顶栏为搜索 +「记录剪切图片」（默认不勾选）；列表行之间有分割线
- [ ] 时间显示 yyyy-MM-dd HH:mm:ss
- [ ] 不打开剪贴板工具时复制 → 打开后能看到；退到托盘再复制 → 回来仍能看到
- [ ] 切到其它工具期间复制，再回到剪贴板历史能看到
- [ ] 写回剪贴板后列表不立刻多出一条重复记录
- [ ] 默认不勾选「记录剪切图片」时复制截图/图片不入库；勾选后复制截图列表有缩略图（不是黑块）；写回为原图、粘贴到画图清晰；放大查看图片按原图像素、文本靠顶部；取消勾选后新图片不再入库，已有条目仍在
- [ ] 任务计划、剪贴板、账号备忘、笔记（含新增下拉）、托盘右键菜单有图标
- [ ] 点状态栏右侧「内存 n MB」弹出明细（工作集/专用/托管堆/当前工具/剪贴板条数）；点「回收内存」数字下降或提示稍后再试；关闭后状态栏刷新
- [ ] 剪贴板被占用时复制 → 提示「复制失败：剪贴板被占用，请稍后重试」，不弹全局异常
- [ ] 剪贴板被占用时编辑器 Ctrl+V → 不崩溃、不插入（可编辑框与只读输出框都验证）
- [ ] 反复切换截图/比对/格式化等工具后，任务管理器内存能回落、不持续攀升

### 文件整理 / 文件查找 / 批量重命名 / 重复文件
- [ ] 文件整理：选目录 → 规则 → 预览（默认不勾选）→ 勾选后执行 → 「撤销上次整理」确认框列出现位置/原位置 → 文件回原处
- [ ] 规则条件选「早于指定日期」时，表格上方出现日期框；切到其它条件日期框隐藏；切条件不闪退
- [ ] 删除规则弹出二次确认（匹配条件/条件值/目标目录/是否启用）；不能删光全部规则
- [ ] 整理成功后切到其它工具再回来，「撤销上次整理」仍可用
- [ ] 原位置已有同名文件或整理后的文件已不在时，撤销跳过并提示
- [ ] 文件查找：关键字 → 结果列表 → 「定位到文件夹」
- [ ] 批量重命名：规则 → 预览 → 执行 → 撤销
- [ ] 重复文件查找：选目录 → 按哈希分组 → 定位/删除

### 端口 / 文件占用 / Hosts / 注册表
- [ ] 端口占用：列出端口→进程映射 → 结束进程
- [ ] 文件占用：选文件 → 列出占用进程 → 结束进程
- [ ] 端口占用、文件占用界面顶部有黄色权限/风险提醒
- [ ] Hosts：增删改映射 → 保存生效；表头在深色/浅色主题下都清晰；表格字体比其它表格大约两号
- [ ] Hosts 启用：去掉行首空格和 `#` 后空格；禁用：行首只加 `#`、后面不加空格；IP/域名间距与行尾注释保持不变；勾选/取消启用未保存时整行琥珀色警告底，保存后恢复
- [ ] Hosts、注册表界面顶部有黄色权限/策略提醒
- [ ] 注册表：只读浏览、能复制路径

### 取色器 / 色盲模拟
- [ ] 屏幕取色 → HEX/RGB/HSL 正确 → 左键确定
- [ ] 色盲模拟：选图 → 各色盲视角预览

### 窗口置顶 / 防止睡眠
- [ ] 窗口置顶：选窗口 → 置顶/取消；列表行之间有分割线
- [ ] 防止睡眠：开启后系统不自动睡眠
- [ ] 防止睡眠界面顶部有红色合规提醒（勿对抗管理员强制睡眠）

### 图片 / 二维码生成
- [ ] 图片：批量压缩/缩放/格式转换 → 输出正确
- [ ] 二维码生成：文本生成二维码 → 保存 PNG

### UUID / ULID / 密码
- [ ] 导航只有「ID 与密码生成」一处入口，无独立 ULID 工具
- [ ] 可切换 UUID v4 / ULID 并批量生成、复制

### Markdown 预览 / 正则可视化
- [ ] Markdown：输入 → 实时预览渲染
- [ ] GFM 表格 / `~~删除线~~` / 任务列表渲染正确，不再像源码管道符原文
- [ ] 预览区查找：输入不立即搜，点「查找」或 Enter 才搜；Enter 下一个、Shift+Enter 上一个、Esc 清空
- [ ] 预览标题栏对角箭头可窗口内最大化/还原，按钮不被预览挡住
- [ ] 正则可视化：输入正则 → 显示中文结构解释 + 语法高亮

### 本机信息 / 证书解析 / JSON Schema / SemVer / Unicode 检查
- [ ] 本机信息：显示 IP/MAC/主机名/系统版本，可复制；Win11 正确显示「Windows 11」
- [ ] 证书解析：选证书文件 → 解析主体/有效期/指纹
- [ ] JSON Schema：Schema 校验 / 从 JSON 反推 Schema
- [ ] SemVer：版本号比较、范围判断
- [ ] Unicode 检查：码点/UTF-8/UTF-16/HTML 实体显示

### 后台任务 LoadingOverlay
- [ ] 哈希/文件查找等耗时任务出现遮罩 + 旋转指示；任务完成后消失
- [ ] 文件查找连点两次搜索：第二次搜索期间遮罩仍在，直到结束（旧任务取消不应关掉新任务遮罩）
- [ ] 切走模块后遮罩消失，且可继续使用其它工具
- [ ] 格式化/编解码/行处理/命名转换：输入即处理，无遮罩、无「正在格式化」条，快速连输结果不丢

### 启动 / 设置
- [ ] 首次运行弹出欢迎引导，关闭后不再出现；设置里可再次打开
- [ ] 点标题栏关闭 / Alt+F4 → 弹出「最小化到托盘 / 退出」；取消留下；确认托盘则隐藏；确认退出则结束进程
- [ ] 勾选「不再提醒」后下次关闭按上次选择执行；设置里「关闭时再次询问」可恢复弹窗
- [ ] 托盘右键「退出」不弹上述窗，仍走原「确定退出 IntraBox？」确认
- [ ] 设置里数据目录显示 %LOCALAPPDATA%\IntraBox\Data；更改目录时复制并出现 Loading，完成后新路径生效；不能选程序目录内
- [ ] 工具显隐按分类、一行四列；全部显示/隐藏；至少保留一个才能保存；「调整顺序」打开表格树形列表（分类/工具缩进），每行右侧置顶/上移/下移/置底，可返回显隐
- [ ] 导航默认顺序为效率工具（剪贴板、启动器、任务计划、笔记、账号备忘）、系统工具、格式化、截图…；保存后侧栏立即变化；恢复默认排序后未再改动则不写自定义顺序；设置始终在导航底部
- [ ] 任务计划：新建与编辑均为右侧抽屉；保存按钮固定在底栏；抽屉可最大化/还原（最大化盖住模块标题与工具顶栏，还原为工作区 70% 宽），主窗口放大缩小时抽屉跟随
- [ ] 任务 ID：默认勾选自动生成且不可改；取消勾选后清空，可填内网工单号；保存必填；已有自动 ID 取消再勾选应恢复原编号而不是新号
- [ ] 计划完成时刻为下拉框，默认 15:00；不能选/填早于当前的时间；详情为带工具栏的富文本（加粗/斜体/下划线/列表/对齐/字体/颜色/插图）；新建任务详情为加粗标签「【任务标题】:」「【任务来源】:」「【任务描述】:」；删改标签后点保存会警告并确认是否继续（默认否）；旧任务「任务标题:」仍能列出标题；插图为缩略图，点击另窗放大；创建/修改/完成时间在详情最底部
- [ ] 列表含创建时间、修改时间；点优先级/标题/创建时间/修改时间/计划完成表头可排序；优先级高红、中蓝、低灰；计划完成日期早于今天时该列、编辑页、提醒窗、xlsx 与月历日期为红色；文字过长省略且悬停可见全文；列表无横向滚动条
- [ ] 首次使用出现一条示例待办（标题带【示例】，含何时建任务与截止日期/提醒填法），删除后重启不会再生成；改过标题（去掉【示例】）或正文/富文本格式/插图后升级软件，该条不被覆盖；未改过的示例可随版本更新
- [ ] 导出 xlsx 先选全部/待办/已办；默认文件名以 yyyyMMddHHmmss 为前缀；描述按文本写入不把数字当日期；列宽够读；详情插图嵌入「图片」列
- [ ] 提醒在右下角弹出并整窗柔和闪烁；预览提醒同样；不出现在任务栏；弹窗展示提醒时刻（与计划完成分开）；默认到点后共 3 次、每 10 分钟一次；关掉当前窗后到点仍会再弹剩余次数；错过某一档超过约 2 分钟不补弹；改提醒时刻后旧的已提醒清掉、新时刻会弹；点「稍后」按该任务间隔（默认 10 分钟）后再弹一次；点「今日不再提醒」为黄色警告按钮（预览同样有），取消确认则仍会按规则提醒，确认后当天不再弹、明天仍按原频次（详情里频次不变）；选「仅计划完成当天」须填计划完成时间，未填不能保存
- [ ] 任务详情「保存并关闭」会保存后收起抽屉回到列表；可勾选自动保存（默认关）；可勾选锁定，锁定后只能查看，不能编辑、删除或改已办/待办，即使勾了自动保存也不写入；已办仍只读且不显示锁定/自动保存勾选
- [ ] 编辑后未点保存，点关闭/遮罩/切 Tab/切走模块会弹出是否保存：是才写入，否丢弃，取消留下
- [ ] 每次实际修改后列表、详情、xlsx 中的修改时间会更新；标记已办/待办也会更新
- [ ] 已办列表有完成时间，为标记已办的时刻；改回待办后清空
- [ ] 右键标记已办/待办只改状态，不打开详情抽屉；过期任务标记已办不弹 SelectedDate 异常；已办列表标记为待办后仍停在已办 Tab，该条从已办列表消失
- [ ] 详情里点缩略图打开独立看图窗，可放大/缩小/滚轮缩放，不是在编辑器里拉大图片；点击富文本空白或文字不弹「FlowDocument 不是 Visual」异常
- [ ] 侧栏抽屉可滚动看到提醒频次与底栏保存；还原宽度约为工作区 70%；最大化后仍可滚动
- [ ] 待办/已办为列表上方 Tab；预览提醒可弹出测试窗
