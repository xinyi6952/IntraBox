# IntraBox（内聚）产品设计文档

**版本**：V1.7  
**日期**：2026年9月  
**产品名称**：IntraBox（内聚）  
**定位**：面向内网工作者与开发者的绿色免安装聚合效率工具  
**支持平台**：Windows 7 SP1 及以上（仅 64 位；32 位进程地址空间不足，大文本格式化/比对会内存溢出）
**运行方式**：绿色免安装（解压即用），纯本地运行，无网络依赖，按需加载模块

---

## 1. 产品概述

### 1.1 产品名称
- 中文名：内聚
- 英文名：IntraBox
- 全称：IntraBox（内聚）—— 内网效率聚合工具

### 1.2 产品定位
IntraBox 是一款专为内网环境设计的桌面聚合工具，将截图标注、文件管理、内容处理、网络检测、文本比对及常用开发小工具整合在一个轻量、绿色、安全的程序中，解决内网工作者工具碎片化、找文件难、截图不可搜、格式处理依赖在线工具等痛点。

### 1.3 核心设计原则
- 绿色免安装，支持 Windows 7+
- 全部功能本地运行，数据不出本机
- 按需加载、用完销毁，保证最小化运行
- 操作安全（预览确认 + 撤销 + 完善容错）
- 历史记忆：每次打开自动恢复上次内容与状态
- 现代简洁的界面风格，操作高度简化，尽量自动化

### 1.4 目标用户
- 内网开发者、测试、运维
- 产品、技术支持、文档编写人员
- 对安全与合规有要求的企业内网用户

### 1.5 开源与仓库
源码以 [Gitee](https://gitee.com/xinyi6952/IntraBox) 为主仓库（日常版本管理、Issue、Pull Request）；[GitHub](https://github.com/xinyi6952/IntraBox) 为镜像，由 Gitee 推送同步。详见 [开源仓库](开源仓库.md)。

## 2. 技术选型

### 2.1 总体原则
- 兼容 Windows 7 及以上
- 绿色免安装（单文件夹优先）
- 低内存与 CPU 占用
- 无强制额外运行时
- 便于安全扫描与源码审计

### 2.2 推荐技术栈

| 模块 | 推荐技术 | 说明 |
|------|----------|------|
| 开发语言 | C# | 生态成熟，Windows 原生支持好 |
| 运行时 | .NET Framework 4.7.2 / 4.8 | 兼容 Win7，绿色部署友好 |
| 界面框架 | WPF（优先） | 便于实现现代界面 |
| 截图与绘制 | System.Drawing + 自研画布 | 支持实时工具栏绘制 |
| OCR | Windows.Media.Ocr（Win10+） + Tesseract/RapidOCR ONNX 备用 | Win7 使用内置备用引擎 |
| 文件操作 | System.IO | 原生 API |
| Excel 处理 | ClosedXML 或 NPOI | 无需安装 Office |
| 文本比对 | DiffPlex + DiffPlex.Wpf | 支持左右对照、行号、差异导航与合并 |
| 网络检测 | System.Net.Sockets + Ping | 原生实现 |
| 配置与历史 | 本地 JSON 文件 | 默认 `%LOCALAPPDATA%\IntraBox\Data`，可在设置中更改 |
| 打包方式 | 单文件夹发布 + 可选 DLL 嵌入 | 减少文件数量 |

### 2.3 架构与资源控制
- 托盘常驻主程序，体积与内存最小化
- 功能模块按需加载：只有用户进入某个工具时才创建对应控件与资源，离开时销毁或释放
- 截图、OCR、大文本比对等重资源模块严格按需创建与释放
- 配置、历史、规则全部本地 JSON 存储

## 3. 界面与交互设计

### 3.1 整体布局

采用左侧导航 + 右侧内容区的经典现代布局：

- 左侧：功能导航（可折叠），按分类展示；默认按日常使用频率排序，可在设置「工具显隐 → 调整顺序」中以表格树形列表上移下移
- 右侧：当前工具的工作区，顶部为简洁的操作栏
- 底部：轻量状态栏（左侧当前工具/提示，右侧内存工作集；点击内存可查看工作集/专用/托管堆并手动回收）
- 托盘图标支持右键快捷菜单

### 3.2 现代UI风格要求（重要）

- 采用现代扁平化设计，参考 VS Code、Windows 11、DevToys 等产品
- 严禁 Windows 7 老旧风格
- 界面干净、留白充足、层级清晰
- 代码展示区域必须具备现代编辑器观感：等宽字体、行号、当前行高亮、选中高亮、轻微边框或背景区分
- 支持浅色 / 深色 / 跟随系统主题（设置中切换，默认深色）
- 按钮少而精，主操作突出，次要操作图标化或收纳

### 3.3 操作简化与自动化原则（重要）

- 能自动完成的动作优先自动完成
- 大幅减少按钮数量，降低用户点击次数
- 主操作视觉突出，次要操作弱化
- 状态反馈清晰友好，错误提示轻量且明确

### 3.4 格式化工具交互要求

- 用户粘贴或输入内容后，自动进行美化
- 切换格式时自动重新格式化
- 提供一键复制结果
- 格式错误时给出清晰友好的错误提示（不崩溃，保留原内容）
- 缩进方式可切换（2空格 / 4空格等），但操作应尽量简单

### 3.5 文本比对工具交互要求

- 支持直接输入文本 或 选择文件
- 输入文本或选择文件后，自动执行比对并展示结果（无需再点“开始比对”）
- 左右分栏展示，差异高亮清晰
- 显示行号
- 支持上一个 / 下一个差异快速定位（类似 IDEA Git 更改视图）；定位时当前差异块以覆盖色 + 左侧竖条高亮，清空或类型不一致后高亮消失
- 支持左右内容合并（左合并到右、右合并到左）
- 内嵌搜索条（Ctrl+F）：输入不自动搜索，点「查找」或按 Enter 才搜索；Enter 下一个、Shift+Enter 上一个、Esc 关闭；可切换左侧/右侧、大小写/全字/正则
- 技术实现参考 DiffPlex + DiffPlex.Wpf

### 3.6 按需加载与销毁策略

- 主程序启动时仅加载托盘、导航框架和配置
- 用户点击某个工具时才实例化该工具的界面与资源
- 切换离开工具时默认销毁（最大化省内存），可在设置中调整为缓存最近 N 个工具
- 重资源模块（截图、OCR、大文件比对）使用完毕后强制释放
- 耗时后台任务（哈希计算、文件查找、RSA 密钥生成、二维码生成/解码、文本统计、Unicode 检查、加解密、JSON 转实体类、JSON Schema 校验/推导、文本转 Excel 导出、Base64 文件互转、图片转换）显示统一 LoadingOverlay（半透明遮罩 + 旋转指示 + 文案），任务完成/取消/出错或离开模块时自动隐藏；毫秒级纯内存操作（格式化、编解码、行处理、命名转换）不加遮罩

### 3.7 历史功能

- 每个工具独立记录上次使用状态（输入内容、选项、路径等）
- 切换到该工具或重新打开程序时自动恢复
- 提供清空当前工具历史 / 清空全部历史的选项
- 历史数据落盘到数据根 `history.json`（默认 `%LOCALAPPDATA%\IntraBox\Data`，与 `config.json` 同目录）
- 设置 → 外观：「状态记忆写入延迟」300–1000ms（默认 300），同时作用于 `history.json` 与整理规则 `fileorganize.json`
- 单条超大文本超过阈值不写入，避免撑爆内存与磁盘
- 设置页展示当前数据目录，可更改（复制到新位置并 Loading 锁定界面）或恢复默认；禁止选到程序目录内。改过目录时程序夹留下 `datapath.txt`。不迁移 exe 旁旧 json。

### 3.8 首次引导与启动恢复

- 首次运行弹出欢迎引导：纯本地、无遥测、兼容 Windows 7；关闭后 `FirstRun=false` 持久化
- 设置页可再次打开引导
- 切换工具时写入上次模块 Key；下次启动自动打开该工具；无记录则停留欢迎语
- 点标题栏关闭 / Alt+F4：弹出「最小化到托盘 / 退出」询问（可勾选「不再提醒」写入 `config.json`）；托盘右键「退出」不弹此窗，仍走原退出确认。设置页可「关闭时再次询问」
- 设置「工具显隐」按分类分组、每行 4 列；「调整顺序」以表格树形列表显示分类/工具（工具缩进），每行右侧置顶/上移/下移/置底；设置固定在导航底部；未自定义时默认：效率工具（剪贴板、启动器、任务计划、笔记、账号备忘）→ 系统工具 → 格式化 → 截图 → 文本工具 → 编码转换 → 转换工具 → 文件管理 → 网络工具 → 安全工具 → 生成器 → 数据转换 → 图片工具 → 设计工具 → 开发工具 → 其他工具

### 3.9 任务计划

- 列表为主：右键（含图标）编辑/查看 / 标记为已办 / 标记为待办 / 删除（二次确认）；表头可按优先级、标题、创建时间、修改时间、计划完成排序；优先级按高/中/低着色；计划完成日期早于今天时该日期用红色显示；列宽随窗口分配，过长文字省略，悬停显示全文
- 首次使用会写入一条可删的示例待办（含何时建任务、怎么填截止日期/提醒/工单号）。用户若改过标题（去掉【示例】前缀）或正文/富文本格式（加粗、颜色、高亮等）、加过插图、锁定或已办，版本升级只记下已刷新、不再覆盖该条；未改过的示例仍会随版本更新
- 新建与编辑均为右侧抽屉（还原为工作区 70% 宽，最大化铺满导航右侧整块工作区，盖住模块标题与工具顶栏）；内容过长时可滚动
- 字段：任务 ID（自动 `T-日期-序号` 或手填；已有自动编号取消再勾选会恢复原 ID）、详情富文本编辑器（工具栏：加粗/斜体/下划线/列表/对齐/字体字号/颜色/插图，可拖入 png/jpg/gif/bmp；图在编辑区为缩略图，点击另窗查看大图并可缩放；正文固定加粗标签 `【任务标题】:` / `【任务来源】:` / `【任务描述】:`，保存时若标签缺失、乱序或新旧混用则警告并确认是否继续；旧任务无书名号前缀仍识别）、优先级、计划完成时间（不可早于当前时间）、提醒频次（默认每天 15:00，到点后共 3 次、每 10 分钟一次，可改；「仅计划完成当天」须填写计划完成时间；改时刻会清掉当天已提醒；已办不提醒、不维护频次）；创建/修改/完成时间显示在详情最底部
- 提醒弹窗出现在屏幕右下角（托盘附近），整窗柔和闪烁，不抢任务栏；预览与到点提醒同一形态（含「今日不再提醒」）；弹窗展示提醒时刻；到点后按次数间隔再弹，每档只在到点后约 2 分钟内弹出、错过不补弹；「稍后」按该任务间隔（默认 10 分钟）到期后再弹一次；「关闭」只收掉当前窗，剩余次数与后续周期仍提醒；「今日不再提醒」为黄色警告按钮，二次确认（默认否）后当天不再弹，明天起仍按原频次
- 任务详情可「保存」或「保存并关闭」，可勾选自动保存（默认关）；可勾选锁定（勾选会记住），锁定后只能查看，不能编辑或删除，即使勾了自动保存也不写入；未保存就关闭抽屉、切 Tab/日历、切走模块时弹出是否保存，确定后才写入
- 已办只能查看，改回待办后才能编辑；已办列表显示完成时间（手动标记为已办的时刻）
- 数据在数据根 `todos\`，`index.json` 带 version；详情抽屉还原宽度为工作区 70%，可最大化

### 3.10 笔记

- 列表 + 右侧抽屉（与任务计划同类）；打开默认最大化铺满导航右侧工作区，可还原为工作区 90% 宽
- 新增为下拉（普通笔记 / Markdown / 目录）；默认标题「无标题笔记」「无标题Markdown」「无标题目录」，同目录重名加序号
- 类型筛选为下拉（全部/普通/Markdown）；可勾选自动保存（默认关闭）；可勾选锁定（勾选会记住；锁定后只能查看，不能编辑或删除，即使勾了自动保存也不写入）；保存 / 保存并关闭 / Ctrl+S；未勾选自动保存时离开抽屉会询问是否保存；置顶；表头可按置顶/类型/标题/创建/修改时间在同级排序；列表为树形（缩进+展开）；目录可嵌套（最多 8 层、合计 200 节点）；笔记可移动到其它目录或根目录；列表与「新增」下拉菜单含图标
- 普通笔记：富文本工具栏（图标化，与任务计划同类）+ 段落号（独立行号色）+ 底部「第 n 段 / 共 m 段 · 字数」；Markdown：AvalonEdit 行号用笔记专用色，默认只编辑，可预览或分栏
- 首次进入有示例普通笔记（联调纪要：何时用普通笔记、怎么保存/插图）与 Markdown（排障手册：预览/分栏、待办与代码块）各一篇，可删。用户若改过标题（去掉【示例】前缀）或正文/富文本格式、加过插图或锁定，版本升级只记下已刷新、不再覆盖该条；未改过的示例仍会随版本更新
- 数据在数据根 `notes\`

### 3.11 账号备忘

- 独立效率工具（不并入笔记）。列表是「分类」（一个系统/场景一篇），右侧抽屉为账号表；编辑页可勾选锁定（勾选会记住；锁定后只能查看，不能编辑或删除，即使勾了自动保存也不写入），可勾选自动保存（默认关）
- 一行：平台可空，自由命名；URL 可空；多个平台用 `/`（或顿号、逗号）写在同一格（多平台一账号）；同一平台多行不同账号（一平台多账号）；账号和密码必填
- 按行勾选「加密」：若尚未设置查看密码则先设置；勾选后立刻加密，账号密码显示为掩码。取消勾选：未验证过则先验证查看密码，再显示明文。未勾选的行明文保存。每篇分类一个查看密码；本次打开编辑页验证一次即可，关闭后再进仍需验证；忘记无法找回
- 复制块格式为「平台:」「URL:」（无 URL 则省略该行）「账号:」「密码:」；也可只复制账号或密码；可复制/导出当前分类全部账号（记录之间空一行），并按同一格式导入追加；含加密行时先验证查看密码；默认不写入剪贴板历史
- 首次两篇可删示例：一平台多账号（GitLab alice/bob）、多平台一账号（GitLab/Jenkins/禅道）
- 数据在数据根 `vault\`

### 3.12 启动器

- 全局热键（默认 Ctrl+Alt+L，设置可改，须含 Ctrl 或 Alt）弹出浮层；主窗口在托盘时仍有效；再按一次热键或 Esc / 失焦关闭并销毁
- 空查询：置顶收藏 → 最近使用 → 可见工具（工具条数有上限）。有关键字才搜待办标题、笔记标题、账号分类名；收藏可按名称或所在目录路径搜；永不搜密码或加密账号；不扫描开始菜单
- 结果最多约 50 条；排序：置顶 > 最近 > 名称开头 > 包含
- 收藏可手加程序 / 文件夹 / 文件 / 内网 URL（仅 http/https）；目录可嵌套（最多 8 层、合计 200 节点）；文件可指定打开方式（空则系统默认）；程序可勾选「打开前二次确认」（默认勾选，防误触）；可打开 .bat（程序或文件），仍不打开 .cmd/.vbs/.ps1；相同程序已在运行时再开一份会二次确认（与勾选无关）。目标丢失时提示、不崩溃。最近 30
- 左侧「启动器」页与任务计划同类：单行顶栏 + 树形表格 + 右侧抽屉（默认不最大化，还原约 70% 宽）。顶栏「新增」下拉（新增收藏 / 新增目录）；操作列仅打开（收藏）、移动（收藏，选目标目录或根目录）、删除；置顶 / 编辑 / 复制 / 新增等在右键菜单。复制名称加「 副本」（目录连子树）。删除二次确认（删目录含下属）。表单校验失败红字。日常靠浮层。数据 `launcher.json`（旧扁平分类字段启动时迁成目录节点），换数据目录时一并复制

### 4.2 各功能详细描述

#### 4.2.1 屏幕截图
- 全局热键唤起（可自定义）
- 支持矩形、窗口、全屏
- 截图后显示浮动工具栏：矩形、圆形、箭头、画笔、文字、马赛克/模糊、撤销/重做、确认、取消、保存、复制、钉在桌面
- OCR 识别后文字可直接选中复制
- 输出方式：剪贴板、本地文件、置顶悬浮窗
- 容错：截图失败提示权限问题；OCR 失败允许仅保存图片

#### 4.2.2 文件整理
- 每条规则 = 匹配条件（扩展名 / 文件名包含 / 正则 / 大于指定大小 / 早于指定日期）+ 自定义目标目录
- 「早于指定日期」：选中该规则后，在表格**上方**的日期框填写；条件值列仍为文本，不在单元格内嵌 DatePicker
- 目标目录支持变量：`{ext}` `{type}` `{name}`。根目录固定为当天日期（yyyy-MM-dd），不必再写 `{date}`
- 规则永久保存到数据根 `fileorganize.json`，与 `history.json` 的 LRU 隔离
- 核心流程：选择源目录 → 配置规则 → 预览（文件默认全部不勾选，只有勾选的才会移动）→ 确认后移动 → 「撤销上次整理」
- 「撤销上次整理」：仅在成功移动至少一个文件后可用；确认框列出将移回的文件（现位置 / 原位置）；原位置已有同名文件或整理后的文件已不在则跳过并提示；撤销后记录清空。记录单独保存在 `fileorganize-undo.json`，切走工具再回来仍能撤销
- 删除规则需二次确认，展示匹配条件 / 条件值 / 目标目录 / 是否启用；不能删光全部规则
- 必须预览确认，防止误操作
- 容错：磁盘空间不足、文件被占用、权限不足时跳过并汇总提示

#### 4.2.3 文件查找
- 选择目录 + 关键字搜索（支持通配符）
- 结果列表显示文件名、路径、大小、修改时间
- 提供「定位到文件夹」按钮，调用资源管理器并选中文件

#### 4.2.4 文本转 Excel
- 支持粘贴文本或选择文件
- 自动/手动指定分隔符
- 预览表格后导出 xlsx
- 文件过大时给出提示

#### 4.2.5 格式化
- 支持格式：JSON、YAML、SQL、XML、Nginx、HTML、CSS、Markdown
- 交互要求：粘贴或输入后自动美化；切换格式后自动重新格式化；一键复制结果
- SQL 格式化推荐风格：关键字大写、SELECT 字段换行缩进、JOIN 不拆行、WHERE 条件清晰缩进
- 格式错误时友好提示错误位置，不崩溃
- 大文本保护：格式化会生成多份全尺寸副本，设有硬顶字符数（64 位约 5000 万字符、32 位约 500 万字符）；超出则停止格式化并给出提示，避免内存溢出。超大文本同时关闭语法高亮以保流畅

#### 4.2.6 端口连通性测试
- 支持 IP/域名 + 端口的 TCP 检测，可选 Ping
- 显示成功/失败与耗时
- 非法输入与超时时友好提示

#### 4.2.7 文本比对
- 技术实现：参考 DiffPlex + DiffPlex.Wpf
- 支持文本比对与文件比对
- 输入文本或选择文件后自动比对
- 左右分栏、显示行号、差异高亮
- 支持上一个/下一个差异导航；当前差异块以覆盖色 + 左侧竖条高亮，便于看清跳到了哪一处
- 支持左右合并
- 可忽略空白、大小写等
- 内嵌搜索条：输入不自动搜索，点「查找」或 Enter 才搜索；切换左侧/右侧时高亮只画在当前侧

#### 4.2.8 剪贴板历史
- 进程启动后用 `AddClipboardFormatListener` 事件驱动记录文本（切换其它工具、窗口退到托盘期间仍继续）；不轮询，纯本地
- 顶栏可勾选「记录剪切图片」（默认关）。关时不解码、不入库剪贴板图片；开后与文本一样监听。取消勾选不删除已有图片条目
- 支持搜索；空白或纯空白文本不入库；相同文本或图片去重，以最后一次为准（提到列表顶部并更新时间）；写回后不另增一条
- 列表右键菜单（含图标）：查看、写回剪贴板、固定/取消固定、删除（二次确认）、清空非固定；顶栏为搜索 + 记录剪切图片；列表行之间有分割线
- 图片从 PNG / DIB 解码（不走 WPF `GetImage`，避免 32 位 DIB 全 0 Alpha 预览成黑块）；列表显示独立缩略图（最长边 128px）；内存中另存原图 PNG 供查看与写回，避免只写回缩略图发糊；写回同时放入 PNG 与 24 位 DIB
- 放大查看时文本靠顶部、图片按原图像素显示
- 历史条数可在设置中配置：默认 20，范围 1–200；下调时优先丢掉未固定项；图片/文本受设置中的体积上限约束

#### 4.2.8b 任务计划
- 列表右键（含图标）：待办为编辑，已办为查看；标记为已办/待办、删除（二次确认）；已办不提醒、不可编辑
- 列表含创建时间、修改时间；点优先级/标题/创建时间/修改时间/计划完成表头可排序；优先级高红、中蓝、低灰；计划完成日期早于今天时列表、编辑页、提醒窗与导出 xlsx 该日期为红色；列过长省略，悬停显示全文；无横向滚动条
- 首次进入若尚未写入过示例，会有一条【示例】待办（联调说明：何时建任务、截止日期/工作日提醒/工单号怎么填），可删。用户改过标题（去掉【示例】前缀）或正文/富文本格式、加过插图、锁定或已办后，版本升级不再覆盖该条，只升级示例版本号；未改过的仍刷新
- 导出 xlsx 在列表上方（待办/已办同一行右侧），不在顶部工具栏；先选全部/待办/已办，默认文件名为 `时间-范围.xlsx`；详情插图嵌入「图片」列
- 新建与编辑均为右侧抽屉，可最大化/还原；最大化铺满导航右侧（含模块标题与工具顶栏）；还原宽度为工作区（不含左侧导航）的 70%；提醒频次下拉、时刻与到点后次数在同一分组框内，下拉完整可见
- 详情正文固定为加粗标签 `【任务标题】:` / `【任务来源】:` / `【任务描述】:`（新建与示例即为此模板）；保存时若标签被删、顺序打乱或与旧版 `任务标题:` 混用，弹出警告确认是否继续；否不写入。自动保存遇到损坏格式会跳过本次写入，直到手动确认或改回模板。旧任务无书名号前缀仍可识别标题/来源/描述
- 关闭详情（含点遮罩、切 Tab/日历、切走模块）时：勾选自动保存则直接写入（格式损坏时仍会弹出确认）；锁定时不自动保存；否则若有未保存改动则询问是否保存，确定后才写入；选否则丢弃，取消则留下
- 计划完成时间不能早于当前时间；已有自动 ID 取消再勾选「自动生成」会写回原编号
- 提醒默认每天 15:00，到点后共 3 次、每 10 分钟一次（可改次数与间隔）；每档只在到点后约 2 分钟内弹出、错过不补弹；改提醒时刻/规则会清空当天已提醒、今日不再提醒与稍后，使新时刻生效；提醒窗贴屏幕右下角并整窗柔和闪烁，展示提醒时刻；进程在托盘时仍弹出；点「稍后」按配置间隔到期后再弹一次；点「关闭」不取消后续提醒；点「今日不再提醒」经二次确认后当天不再弹，明天起仍按原频次；「仅计划完成当天」须填写计划完成时间
- 已办列表展示完成时间（标记已办的时刻）；已办详情只读，改回待办后才能编辑；在已办列表标记为待办后仍停留在已办 Tab
- 待办可勾选锁定；锁定后只能查看，不能编辑、删除或改已办/待办状态，即使勾了自动保存也不写入；自动保存默认关闭
- 月历展示待办（按优先级色点）与已办任务，含未办且日期已过的格子日期为红色；上月/下月为箭头按钮；导出 xlsx 清单

- 展示 CPU 逻辑核心数与处理器名称；物理内存总量与可用量
- 列出活动网卡的 IPv4/IPv6、MAC 地址
- 全部信息可一键复制；进入模块时自动刷新
- 纯本地读取，不访问网络

#### 4.2.16 URL / HTML / Unicode 编解码
- URL：`EscapeDataString` / `UnescapeDataString` 编解码
- HTML：实体编码与解码（如 `&lt;` ↔ `<`）
- Unicode：`\uXXXX` 转义与明文互转
- 选择类型后即时转换；一键复制结果
- 非法输入给出轻量错误提示，不崩溃

#### 4.2.17 端口占用查看
- 列出本机 TCP/UDP 端口与进程映射：协议、本地地址、远程地址、状态、PID、进程名
- 支持按端口或进程名筛选、列表排序、复制选中行
- 可结束选中进程（需确认）；权限不足或进程已退出时明确提示
- 界面黄字提示：结束进程可能影响业务或安全软件，系统进程通常需要管理员权限
- 通过解析 `netstat -ano` 获取数据，纯本地、无需第三方依赖

#### 4.2.18 命名转换
- 支持 camelCase、PascalCase、snake_case、SNAKE_CASE、kebab-case、全大写、全小写互转
- 输入变更后实时转换，可一次输出全部风格
- 一键复制当前结果

#### 4.2.19 JSON 转实体类
- 粘贴 JSON 后推断字段类型，生成 C# 或 Java 模型类
- 支持对象嵌套与数组；输出到只读代码编辑器，可复制
- JSON 非法时提示原因，不覆盖上次有效结果以外的说明

#### 4.2.20 加解密
- 对称：AES（256）、DES；非对称：RSA（加密/解密/签名/验签）
- 支持生成 AES/DES 密钥与 RSA 密钥对（XML）
- 明文/密文以文本处理，密文默认 Base64；密钥可手动填写
- 密钥错误、数据过长或填充失败时友好提示

#### 4.2.21 二维码生成
- 文本生成二维码，预览并可保存为 PNG、复制到剪贴板
- 从图片解码二维码（识别失败时提示）；纯本地完成
- 空文本或生成失败时不崩溃

#### 4.2.22 URL 解析
- 使用 `System.Uri` 解析协议、主机、端口、路径；正则拆分 query（`?a=1&b=2`）、fragment（`#hash`）、用户信息（`user:pass@`）
- 结果分类展示，各字段可一键复制
- 非法 URL 友好提示，不崩溃；纯 BCL，无网络请求

#### 4.2.23 行处理
- 多行输入，按钮执行：去重（保序 / 去重后排序）、排序（升序 / 降序 / 自然序）、删空行、删首尾空白、每行加前缀/后缀
- 输出只读区，可复制；纯 BCL

#### 4.2.24 文本统计
- 统计字符数（含/不含空白）、字数、行数、段落数
- 词频 Top N、单字符频率；纯 BCL，大文本受设置中的体积上限约束

#### 4.2.25 批量重命名
- 选择目录或文件；规则：前缀、后缀、序号、查找替换、正则
- 执行前预览新旧文件名；支持撤销最近一次重命名
- 文件占用或重名冲突时提示并跳过；纯 BCL

#### 4.2.26 文件占用查看
- 选择文件，列出占用它的进程（进程名、PID）
- 优先 P/Invoke Restart Manager（`RmStartSession` / `RmRegisterResources` / `RmGetList`），失败则独占打开试探
- 可结束所选进程（需确认）；权限不足时友好提示；兼容 Windows 7+
- 界面黄字提示：结束占用进程可能中断正在运行的程序或安全软件

#### 4.2.27 Hosts 编辑器
- 读写 `C:\Windows\System32\drivers\etc\hosts`
- 列表展示每条映射（IP、域名、注释），支持增删改、注释切换、保存
- 启用：去掉当前行行首空格，以及 `#` 与内容之间的空格；禁用：去掉行首空格后只加 `#`，`#` 后不加空格。IP 与域名之间的间距、行尾注释等其余内容不动；未改启用状态的行原样写回
- 加载后无默认选中；删除按当前选中行生效（与「启用」勾选分离）
- 无管理员权限时提示以管理员运行，不静默失败
- 界面黄字提示：修改 Hosts 需要管理员权限，并可能影响本机域名解析与组织网络策略
- 启用勾选或取消后未保存时，该行整行琥珀色警告底；保存或改回原状态后恢复
- DataGrid 表头随深色/浅色主题（深底浅字或浅底深字），不用系统默认白表头；表格字号 15（比全局默认大两号）

#### 4.2.28 窗口置顶
- `EnumWindows` 列出可见窗口；选中后 `SetWindowPos(HWND_TOPMOST)` 置顶或取消
- 可勾选对本工具自身窗口置顶
- 窗口列表行之间有分割线

#### 4.2.29 防止睡眠
- 开关按钮：开启时 `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)` 阻止系统睡眠
- 关闭或退出程序时恢复；开关状态在切换模块后仍保持，直到用户关闭
- 界面红字合规提醒：可能违反组织电源管理/安全策略，请勿用于对抗管理员强制睡眠；仅建议长时间编译/下载时使用，风险自负

#### 4.2.30 证书解析
- `X509Certificate2` 解析 `.cer` / `.pfx` 文件或粘贴 Base64/PEM
- 展示颁发者、使用者、有效期、序列号、指纹、签名算法，可复制；纯 BCL
- PFX 需密码时提示输入；解析失败不崩溃

#### 4.2.31 ULID 生成
- 已并入 4.2.14 ID 与密码生成，不再单独注册导航入口

#### 4.2.32 Unicode 字符检查
- 输入字符/字符串，逐字符显示码点（U+XXXX）、UTF-8 / UTF-16 字节、HTML 实体、Unicode 类别
- 纯 BCL；空输入不崩溃

#### 4.2.33 SemVer 版本比较
- 两个语义化版本号 + 操作符（`>` `<` `=` `>=` `<=`），或判断是否满足范围（`^1.2.0`、`~1.2`）
- 自实现解析与比较；非法版本号友好提示

#### 4.2.34 重复文件查找
- 选择目录，按文件大小初筛 + SHA256 哈希找内容重复文件
- 同哈希分组展示；支持「定位」与「删除选中」（删除前确认）
- 大目录后台线程 + 进度，不卡 UI；纯 BCL

#### 4.2.35 图片压缩缩放转换
- 批量选图或目录；缩放（比例 / 指定宽高）、格式转换（PNG / JPG / BMP / GIF）、JPEG 质量
- `System.Drawing` + `EncoderParameters`，高质量重采样；输出到指定目录，覆盖前提示
- WebP 本版不支持，界面标注后续

#### 4.2.36 Markdown 预览
- 左编辑右预览；Markdig（纯托管，net48 / netstandard2.0）解析为 HTML，启用高级扩展（GFM 表格 / 删除线 / 任务列表 / 自动链接等），pipeline 全局缓存
- 预览只读、纯本地渲染，不访问网络
- 启动时写 HKCU 本进程 `FEATURE_BROWSER_EMULATION=11001`，让 WPF WebBrowser 以 IE11 文档模式渲染（写入失败则样式降级，不影响功能）
- 预览区支持查找：输入不自动搜索，点「查找」或 Enter 才搜索；Enter 下一个、Shift+Enter 上一个、Esc 清空
- 预览区标题栏对角箭头：窗口内最大化 / 还原（复用 InPlaceMaximize）。放大按钮与 WebBrowser 分属不同行，避免 HWND 空气空间挡住按钮

#### 4.2.37 正则可视化
- 对正则做结构中文解释（如 `^`→行首、`[3-9]`→3~9 中的一个字符、`{9}`→重复 9 次）
- AvalonEdit 正则语法高亮；纯本地，非法正则提示原因

#### 4.2.38 注册表只读浏览
- `Microsoft.Win32.Registry` 只读遍历 HKCU / HKLM
- 树形展开键、列出值（名称/类型/数据），可复制路径
- 只读不写；权限不足的键跳过并提示
- 界面黄字提示：含系统与策略相关配置，未授权环境请勿翻查敏感键；部分键需管理员权限才能读取

#### 4.2.39 JSON Schema 验证
- 用 JSON Schema 校验 JSON 并报错路径；或从 JSON 反推生成 Schema
- 基础子集自实现（type / required / properties / items 等），依赖现有 Newtonsoft.Json
- 非法 JSON 友好提示

#### 4.2.40 色盲模拟
- 输入图片或颜色，模拟红绿色盲 / 蓝黄色盲 / 全色盲视角
- `System.Drawing` 像素颜色矩阵变换；预览 + 导出

#### 4.2.41 屏幕标尺
- 全屏透明覆盖层 + 十字光标；H 水平 / V 垂直 / R 矩形（宽×高）
- 实时显示像素距离，并按屏幕 DPI 换算厘米 / 英寸
- 默认热键 Ctrl+Shift+M（可在配置中改虚拟键）；Esc 关闭
- 纯本地、无依赖

## 5. 容错与异常处理

| 场景 | 处理方式 |
|------|----------|
| 格式错误（JSON/YAML/SQL等） | 明确提示错误位置或原因，不崩溃，保留原内容 |
| 文件过大 | 超过阈值时警告，允许取消或继续 |
| 文件被占用 / 无权限 | 跳过并汇总提示，或中止并说明原因 |
| 目录不存在 | 友好提示并引导重新选择 |
| OCR / 截图失败 | 提示可能原因，允许仅保存图片 |
| 网络检测超时 | 显示超时结果，不卡死界面 |
| 性能压力 | 大文本比对、大文件哈希时给出提示 |

错误提示优先使用轻量方式（状态栏或编辑器下方提示），重要操作才使用弹窗确认。
