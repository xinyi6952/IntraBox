# IntraBox 测试用例文档

本文档说明 IntraBox 的测试方式：**确定性逻辑用自动化测试（`test.bat` 一键跑），交互型功能按手动清单逐项验证。**

## 一、自动化测试（已实现，跑 `test.bat`）

`test.bat` 会构建测试项目 `tests/IntraBox.Tests` 并运行全部 MSTest 用例。当前已覆盖以下确定性逻辑：

| 功能 | 覆盖的用例 | 关键断言 |
|---|---|---|
| JSON 格式化 | 美化/压缩/非法/空输入 | 缩进换行、单行无空格、错误返回 null+信息 |
| 格式化转义 | JSON/XML 去转义与转义往返 | `\"` `\\` `\n` `\u`、`&gt;` `&nbsp;` `&amp;gt;`、SQL 引号、CSS `\61` |
| SQL 格式化 | 关键字大写/子句换行/AND 行首 | 含 SELECT、FROM、缩进 |
| XML 格式化 | 含声明保留/无声明不发明/往返/非法 | 声明与 encoding 保留、二次美化稳定、错误返回 null+信息 |
| 哈希 | MD5/SHA256/差异/ToHex | RFC 官方向量（如 MD5("abc")） |
| Base64 | 编码/往返/非法 | 已知值、往返一致、抛异常 |
| 时间转换 | 乱格式识别/多写法 | Unix 0=1970；ISO/RFC（星期可错）/中文/年月/ISO 周/星期；列出 ISO 与 Unix |
| Win7 兼容 | IE 仿真/TLS/OCR/WebView2 路径/DPI | IE11 认 svcVersion 而非 9.11；空版本按 IE8；缺 VC++ 能识别；Win10+ 才带 TLS 1.3 标志；空 visual 每英寸 96；Fixed 只认 `WebView2Runtime` 下的 exe；`IsWindows10OrNewer` / `IsWindows8OrNewer` 不抛 |
| Edge 压缩包 | 选项/版本比较/已有目录记版本 | 非法选项回到「再问」；CAB 比已解压新才询问，拒绝过的版本不再问；已有内核但没有标记时只写入当前版本、不改文件 |
| ULID | 长度/字符集/两次不同 | 26 位 Crockford Base32 |
| 模块注册 | 无独立 ULID/GIF 入口 | 仅 idgenerator，无 ulidgen、screengif |
| 文本文件编码 | GBK/UTF-8/带 BOM 往返 | 自动检测编码、写回字节一致 |
| Hosts 文件 | 保存/注释空行/启用切换/改动摘要 | 保留注释空行、未改行原样写回；启用去掉行首空格和 `#` 后空格，禁用只加 `#` 不加空格 |
| 防止睡眠 | 时长解析 | 分钟/小时换算、非法输入报错 |
| 护眼模式 | 色温曲线/时段/冲突名/暂停/用眼提醒文案 | 6500K 近白；默认含白天三段；关掉的段不选中、不参与重叠；flux→f.lux；暂停 1h=60:00；提醒未开/未改色/计时中文案；关闭/暂停/未改色不计时 |
| 文件整理 | 匹配/目录展开/日期去重/撤销落盘 | 扩展名忽略大小写、{date} 不与当天重复、规则 JSON 不含撤销记录 |
| 设置历史 | 数字兼容/剪贴板条数夹取 | long/double 兼容、超长字符串不入库；图片条数 0 回落 20、夹取 1–50；超图片上限挤未固定旧图 |
| 剪贴板图片 | DIB/PNG/Alpha/缩略图/DataObject 写回 | 全 0 Alpha 不黑、24 位 DIB 往返、自顶向下、超限只读头、写回含 PNG+24 位 DIB |
| 命名转换 | 分词/各风格/空输入 | camelCase/snake_case、XMLHttp 拆分 |
| URL 解析 | 各字段/query 解码/hash/非法 | scheme/host/port/path、%E4%BD%A0→你好 |
| 预览导航 | 页内锚点/空链/外链 | about:blank#id 与裸 #id 可解析；用户点 about:blank 要取消；http/file 拦截；脚本只插入一次 |
| Unicode 检查 | ASCII/中文/代理对/编码 | U+0041、U+4E2D、😀=U+1F600、UTF-8/16 |
| SemVer 比较 | 解析/比较/^~范围 | 预发布<正式版、^1.2.3<2.0.0 |
| JSON Schema | 推断/校验/错误 | type/properties/required、缺必填报错 |
| 正则解释 | 转义/锚点/字符类/量词/分组 | \d=数字、[abc]=集合、{2,3}=重复 |
| 编解码 | URL/HTML/Unicode 编解码 | 百分号编码、HTML 实体、\u 转义往返 |
| 行处理 | 拆行/去重/排序/自然序/前后缀 | file2<file10、保序去重 |
| 文本统计 | 字符/词/行/段落/词频 | 忽略大小写词频、空行分段 |
| 文本转 Excel | 分隔符探测/表格解析/智能分列/列格式 | 逗号/制表符、空行跳过、单元格 trim；按文本类型/关键字/固定宽度；默认文本保留 00001；TSV/HTML 复制跳过「不导入」列 |
| 加解密 | AES/DES 往返、RSA、密钥派生 | 加密解密往返、密文含随机 IV |
| 证书解析 | PEM 解析/格式化 | CN=主体、有效期、指纹 |
| 启动器 | 标题/目录路径匹配/排序/脚本与 URL 校验/树迁移/系统目录/落盘格式 | 置顶>最近>开头>包含、空查询顺序、按收藏目录路径搜、允许 bat、拒绝 cmd/vbs/ps1 与非 http(s)、已在运行判定、旧 Favorites 迁目录、缺 FormatVersion 需回写、损坏 JSON 失败不覆盖、保存含 FormatVersion 且不含 Favorites、打开方式与程序确认、系统快捷方式按存在性收录且不可移动、系统目录可折叠、记事本空白未命名 |
| 产品版本 | 四段全号/打包加一/数值比较 | 界面与文件属性均为 `1.0.0.312`；9 之后为 10；65535 进位 |
| 工作日 | 法定假/调休/用户覆盖/加减工作日 | 2026 国庆放假、10-10 调休上班；用户覆盖优先；2027 无内置表 |
| 下拉筛选 | 开头/包含/子序列 | 「北京」命中显示名；空查询视为全匹配 |
| 表单提示 | 校验红字/成功不红 | 「请填写」为错；「已保存」为成功；「已锁定」仍为错 |
| curl 解析 | bash/cmd/insecure/仅 http(s) | 抽出方法、URL、Header、请求体；不发请求 |
| HTTP 测通解析 | 默认端口/变量替换 | https→443；有值则替换；缺变量失败（与 JobVarHelper.TrySubstitute 一致） |

> 确定性逻辑已全部抽出 `Core/*Helper` 并通过 MSTest 用例；仅「进制类转换」在代码中无独立实现而未单独覆盖。剪贴板监听/写回的 UI 与占用重试仍走下方手动清单。

## 二、手动测试清单（交互型功能，需人工点）

以下功能依赖 UI/系统交互，无法自动化，按「操作 → 期望」逐项验证。

### 截图 / 屏幕标尺
- [ ] 全局热键（Ctrl+Alt+A）能唤起，出现全屏遮罩 + 十字光标
- [ ] 框选区域 → 显示工具栏（默认是「移动/选择」光标，非矩形）
- [ ] 画矩形/箭头/文字/马赛克 → 撤销 → 重做（重做能恢复）
- [ ] 钉在桌面后，工具栏仍显示、仍可标注
- [ ] 保存到文件、复制到剪贴板
- [ ] OCR 识别图中文字，结果可选中复制；失败弹窗须含具体原因（未装 VC++ 2015-2019 x64 或缺少 tesseract41.dll 时提示安装运行库，并带底层详情），不能只显示「调用的目标发生了异常」；`%LOCALAPPDATA%\IntraBox\logs` 当天日志有「OCR 失败」及异常类型
- [ ] OCR 识别中按钮灰掉、提示「正在识别…」；连点或覆盖层与钉图同时点不会并行进引擎，结束后按钮恢复
- [ ] 屏幕标尺：热键或按钮打开 → H/V/R 测量 → 显示像素与厘米
- [ ] 混合 DPI（若有）：把主窗拖到另一缩放比例的屏幕后，标尺/截图/剪贴板看图尺寸仍合理（PerMonitorV2）

### 格式化
- [ ] 粘贴 JSON 后自动美化；切换格式、缩进或压缩会重算；复制结果可用
- [ ] 「转义」默认不处理。选去转义：`{\"a\":1}` 变成可美化的 JSON；`&gt;&nbsp;` 变成大于号和不换行空格。选转义：JSON 出现 `\"` 与 `\\`，XML 出现 `&lt;` `&gt;`，不再美化

### 文本比对
- [ ] 粘贴左右文本 → 状态先变成「比对中…」再出差异（红删绿增）；大文本等待时有遮罩，改字后旧结论不会盖住新一轮
- [ ] 点合并箭头 → 合并 → 撤销（Ctrl+Z）
- [ ] 上一个/下一个差异 → 到顶/到底时提示不循环
- [ ] 上一个/下一个差异时当前差异块有覆盖色 + 左侧竖条高亮；清空或一侧改文本导致类型不一致后高亮消失
- [ ] 拖文件到左右 → 自动加载并比对；GBK/UTF-8 文件不乱码
- [ ] 文件比对 + 合并后点清空 → 弹保存确认
- [ ] Ctrl+F 搜索条：输入不立即搜；点「查找」或 Enter 才搜；Enter 下一个、Shift+Enter 上一个、Esc 关闭
- [ ] 切换左侧/右侧后点查找，高亮只画在当前侧，旧侧不再残留橙色

### 剪贴板历史
- [ ] 复制文字 → 出现在列表 → 双击或右键写回；复制空内容或纯空白不入库；再复制已有内容时列表仍一条并以最新时间为准
- [ ] 搜索、右键「查看」（窗口内最大化，文本靠顶部；图片完整落入窗口、无横竖滚动条、尺寸按屏幕 PixelsPerInch 而非 PixelsPerDip；点「关闭」回到列表）/「写回剪贴板」/「固定」/「删除」（二次确认）/「清空非固定」；顶栏为搜索 +「记录剪切图片」（默认不勾选）；列表行之间有分割线
- [ ] 时间显示 yyyy-MM-dd HH:mm:ss
- [ ] 不打开剪贴板工具时复制 → 打开后能看到；退到托盘再复制文本 → 回来仍能看到；勾选记录图片且设置「藏托盘期间不把剪贴板图片记入历史」时，托盘里复制的图片不入库，打开主窗口后再复制才入库
- [ ] 切到其它工具期间复制，再回到剪贴板历史能看到
- [ ] 写回剪贴板后列表不立刻多出一条重复记录
- [ ] 默认不勾选「记录剪切图片」时复制截图/图片不入库；勾选后复制截图列表有缩略图（不是黑块）；写回为原图、粘贴到画图清晰；放大查看图片完整落入窗口（屏幕像素 1:1，超出只缩小，无滚动条）、文本靠顶部；原图损坏时查看/写回提示失败、不会用缩略图代替；取消勾选后新图片不再入库，已有条目仍在
- [ ] 设置里剪贴板图片条数默认 20、可调 1–50（不超过总条数）；下调后未固定旧图被裁、固定图保留；写回仍是原图不是缩略图
- [ ] 任务计划、剪贴板、账号备忘、笔记（含新增下拉）、托盘右键菜单有图标
- [ ] 点状态栏右侧「内存 n MB」弹出明细（工作集/专用/托管堆/当前工具/剪贴板条数）；数字旁「?」悬停有口径说明（工作集=物理内存/任务管理器口径，专用内存=已提交虚拟内存、可换出、不等于一直占那么多物理 RAM，回收往往降不下专用；托管堆=.NET 对象）；点「回收内存」工作集下降或提示稍后再试，按钮悬停说明专用内存通常不变、托盘空闲超时后也会压工作集；关闭后状态栏刷新；数据根 `gc.log` 增加一行含 `reason=manual`（稍后再试则含 `GC skip`）
- [ ] 剪贴板被占用时复制 → 提示「复制失败：剪贴板被占用，请稍后重试」，不弹全局异常
- [ ] 剪贴板被占用时编辑器 Ctrl+V → 不崩溃、不插入（可编辑框与只读输出框都验证）
- [ ] 反复切换截图/比对/格式化等工具后，任务管理器内存能回落、不持续攀升；切格式化等到时间转换后工作集应下降（重工具会 Trim），切行处理到命名转换不应明显抖动
- [ ] 设置「内存压缩」：点开设置不弹 RangeBase 异常（Minimum/Maximum 均不得报无效值）；默认启动恢复上次工具、托盘空闲 90 秒卸载、高水位 220MB / 低水位 120MB、托盘不记剪贴板图片；关掉卸载后托盘超时只压工作集不卸工具；高水位滑条可拉到 2048MB，低水位上限随高水位（high−20）
- [ ] 笔记/待办/账号备忘开自动保存：改几个字立刻藏托盘，等到空闲卸载后再打开，正文还在（未开自动保存且脏则不卸载、不弹窗）
- [ ] 待办开自动保存、破坏详情模板后藏托盘等到卸载：不弹「格式错误」，未确认损坏前不把坏模板写盘；关抽屉 / 切工具 / Ctrl+S 仍询问
- [ ] 账号备忘开自动保存后藏托盘卸载：不因保存失败弹框；点保存失败仍弹

### 文件整理 / 文件查找 / 批量重命名 / 重复文件
- [ ] 文件整理：选目录 → 规则 → 点预览立刻出现「正在扫描…」→ 预览为树形表格（列：勾选、名称、来源；默认不勾选，只有文件有勾选框）→ 勾选后执行出现「正在移动 当前/总数」，取消后已移动的留在新位置并有说明 → 「撤销上次整理」确认框列出现位置/原位置 → 确认后立刻出现「正在撤销 当前/总数」→ 文件回原处
- [ ] 规则条件选「早于指定日期」时，表格上方出现日期框；切到其它条件日期框隐藏；切条件不闪退
- [ ] 删除规则弹出二次确认（匹配条件/条件值/目标目录/是否启用）；不能删光全部规则
- [ ] 整理成功后切到其它工具再回来，「撤销上次整理」仍可用
- [ ] 原位置已有同名文件或整理后的文件已不在时，撤销跳过并提示
- [ ] 撤销过程中取消：提示已撤销多少个，未处理的下次仍可撤销。撤销记录文件损坏时，再次进入文件整理会提示「上次整理的撤销记录损坏，已清空」
- [ ] 文件查找：关键字 → 结果为树形表格（列：名称、大小、修改时间、路径，可展开）→ 双击文件或「定位到文件夹」；选中目录不能定位文件
- [ ] 批量重命名：规则 → 预览先出进度 → 执行显示「正在重命名 当前/总数」，冲突边做边出现，进行中不能再点执行 → 撤销也有进度。部分失败时提示「已撤销 N 项，失败 M 项」及原因，失败项可再撤销
- [ ] 重复文件查找：选择目录后，页面「目录」框显示该路径。点「开始查找」后按钮变为「停止」，文案「正在枚举文件…」，进度条不定并更新已看到的文件数；哈希进度只增不减。再点只停止，不并行第二轮，结束后按钮回到「开始查找」。查找中切到其它工具会确认。完成后弹窗说明重复组数和文件数。结果为树形表格（列：名称、大小、哈希、路径）→ 定位文件或目录；删除只针对选中的文件
- [ ] 文本转 Excel：粘贴 `00001,2024-01-02` → 预览与导出 xlsx 均为原文（不当成数字/日期）；点击列标题可改数字/日期/不导入
- [ ] 文本转 Excel：默认勾选「限制行数」且为 5000。超过后底栏说明只处理前若干行，预览、复制、导出都不含后面的行。改成更大的数字后能多处理。取消勾选后不再按该数字截断。超过 10 万行仍截断并说明是保护上限。非法数字不生效。超过 5000 行点复制先出现「正在复制…」
- [ ] 文本转 Excel：预览「复制」后粘贴到 Excel/WPS 已分列且 00001 仍带前导零；预览可放大/还原
- [ ] 文本转 Excel：分列方式「按文本类型」将 `张三19900101` 拆成两列；「按关键字」`区` 拆地址；「固定宽度」`6,8,3,1` 拆身份证

### 端口 / 文件占用 / Hosts / 注册表
- [ ] 端口占用：进入后先出现页面和 Loading，再列出端口→进程映射 → 结束进程；刷新中切走会结束 netstat
- [ ] 文件占用：选文件后先看到路径和「正在查询哪个进程占用…」→ 列出占用进程 → 结束进程
- [ ] 端口占用、文件占用界面顶部有黄色权限/风险提醒
- [ ] Hosts：增删改映射 → 保存生效；表头在深色/浅色主题下都清晰；表格字体比其它表格大约两号
- [ ] Hosts 添加：有选中行时插在其下，无选中时加在最后一行下；未保存的新增行为绿色底，保存后恢复
- [ ] Hosts 启用：去掉行首空格和 `#` 后空格；禁用：行首只加 `#`、后面不加空格；IP/域名间距与行尾注释保持不变；勾选/取消启用未保存时整行琥珀色警告底，保存后恢复
- [ ] Hosts、注册表界面顶部有黄色权限/策略提醒
- [ ] 注册表：展开和点选先显示「正在读取…」，慢键不出现空树；失败能看到原因。只读，能复制路径

### 取色器 / 色盲模拟
- [ ] 屏幕取色 → HEX/RGB/HSL 正确 → 左键确定
- [ ] 色盲模拟：顶部「说明」默认折叠，展开后为专业说明（含通过/删除）；类型为红色盲/绿色盲/蓝色盲/全色盲
- [ ] 色盲模拟：进入即有示例图；左为原图、右为模拟；选红色盲或绿色盲后示例里红/绿、「通过」/「删除」在右边变接近
- [ ] 色盲模拟：中间色块行能看出红→模拟、绿→模拟；打开自己的图后立刻「正在生成模拟图…」，完成再换左右图；切换类型时旧图还在并显示等待（超过设置中的文件大小上限则提示不加载）；「回到示例图」恢复；可导出右边 PNG

### 窗口置顶 / 防止睡眠 / 护眼模式
