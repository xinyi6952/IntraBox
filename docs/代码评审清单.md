## 1. 怎么用

| 项 | 约定 |
|----|------|
| **默认范围** | 当前未提交 diff，或 PR 相对默认分支的全部提交。点名了文件/模块则以点名为准。 |
| **节奏** | 功能告一段落或发版前做一次；改账号备忘 / 剪贴板 / 数据目录 / 导航注册时，当次必过对应专节 |
| **产出** | 结论（通过 / 部分 / 失败）+ 可复现问题（文件或行为）+ 是否建议补测试/文档 |
| **原则** | 以「用户可感知结果」验收，不以「能编译」代替；改落盘必看迁移与明文/密文边界 |

**执行顺序**

1. 看 diff 与 §5 触发表，只跑相关专节 + 对应 P0。  
2. 先过 §2 高发模式。  
3. 能跑的自动化先跑：`test.bat`。  
4. 交互项对照 `docs/测试用例.md` 相关条，不要把 44 个工具全点一遍。

## 2. 高发回归模式

| # | 模式 | 典型后果 | 自检一句 |
|---|------|----------|----------|
| R1 | **中文源码无 UTF-8 BOM** | 界面乱码（net48 按 ANSI 读源码） | 新增/改过的 `.cs`/`.xaml` 是否跑过 `tools/add-bom.ps1`？ |
| R2 | **托盘占用 exe** | `build.bat` 失败、跑到的仍是旧程序 | 脚本是否询问结束进程？确认后是否真的杀掉再编？取消是否中止？ |
| R3 | **账号备忘清空明文** | 勾选加密/复制后账号密码变空 | 加密是否只封存 Enc、界面掩码？复制是否先验证再出明文？ |
| R4 | **剪贴板把缩略图当原图 / Alpha 全 0** | 写回黑块、糊图 | 写回是否只走原图 PNG+24 位 DIB？失败是否提示而不是用缩略图？是否补不透明？ |
| R5 | **只改 UI 不改落盘/迁移** | 换数据目录丢数据、旧 JSON 读崩或被空表覆盖 | `DataPaths` 是否拷了新子目录与 `.bak`？缺字段是否有缺省？损坏是否隔离为 `.bak` 而非写空覆盖？保存是否当前结构？ |
| R6 | **抽屉离开不确认** | 未保存内容丢失 | `ILeaveGuard` 是否仍在？自动保存开时是否 flush？ |
| R6b | **忙任务切走不确认** | 后台任务被默默取消或切走后仍跑 | `IBusyTool` / LoadingOverlay 离开是否二次确认？确认后 `OnDeactivated` 是否取消？否是否恢复侧栏选中（含设置）？ |
| R7 | **模块用完不释放** | 切工具内存只涨不回 | `OnDeactivated` 是否释放大图/WebView2/WebBrowser/计时器？重工具切走是否 Idle Trim？托盘超时无未保存是否静默卸载？`LoadingOverlay.Hide` 是否只 Bump 世代、不把 `_gen` 清掉？ |
| R8 | **查看密码会话范围错** | 关抽屉再进仍免验证，或同页反复弹窗 | 验证是否只在**本次打开编辑页**有效？ |
| R9 | **C# 8+ / 乱加 NuGet** | Win7 / net48 编不过或体积膨胀 | 是否仍 C# 7.3？新包是否必要？ |
| R10 | **文档不同步** | 按说明操作对不上 | 设计 / 测试用例 / 使用说明是否跟上行为？ |

## 3. P0 冒烟

> 构建时若托盘有 IntraBox，`build.bat` 会询问是否结束进程（默认否）；确认后杀掉再编。用 `dist\IntraBox` 或当次 Release 产物验证；首次运行场景用 `build.bat test` 的 `dist\IntraBox.test`。

### 3.1 启动与壳

- [ ] 启动单实例；二次启动唤醒已有窗口
- [ ] 点左侧工具或设置：该项立刻选中，右侧出现「正在打开…」，连点只打开最后一次；未选中项悬停高亮；点星标收藏后变黄★且不切换工具，重启仍在
- [ ] 关主窗口按设置进托盘或退出；托盘右键能打开/退出
- [ ] 导航默认：效率工具（剪贴板、启动器、任务计划、笔记、账号备忘、工作日历）在前，设置在底
- [ ] 状态栏当前工具名正确；点「内存 n MB」能打开明细
- [ ] 窗口标题 / 托盘悬停 / 欢迎引导 / 设置底栏 / exe 属性为同一串四段号；设置里点击版本复制出的字符串与界面一致

### 3.2 构建与自动化

- [ ] 含中文的源码带 UTF-8 BOM（`tools/check-bom.ps1`）
- [ ] Release 能编过；`test.bat` **全绿**
- [ ] 默认模式 `build.bat` 会升 `version.txt` 最后一段；`build.bat test` 与 `test.bat` 不升；双击菜单第二问 `Y` 启动新包并关窗，`N` 或 `norun` 不启动；失败窗口停住
- [ ] 未擅自升级语言版本、未无必要加 NuGet

### 3.3 剪贴板历史（有改动或发版前）

- [ ] 复制文本进列表；空白或纯空白不入库；相同内容去重并以最新为准；写回后不立刻多一条重复
- [ ] 复制截图：缩略图不是黑块；写回原图清晰
- [ ] 图片张数上限生效：未固定旧图被挤掉，固定图保留
- [ ] 不打开该工具时复制，打开后仍能看到

### 3.4 账号备忘（有改动或发版前）

- [ ] 勾选加密：先设/验查看密码；界面不显示明文；复制能出明文
- [ ] 取消加密：未验证则先验证，再显示明文
- [ ] 本次打开编辑页验证一次即可；关闭后再进仍要验证
- [ ] 复制块为 `平台:` / 有则 `URL:` / `账号:` / `密码:`；复制全部 / 导出 / 导入往返
- [ ] 默认复制不进剪贴板历史

### 3.5 抽屉与离开

- [ ] 笔记 / 待办 / 账号备忘：未自动保存时关抽屉询问
- [ ] 切走模块再回来，输入/列表不丢

## 4. 分域检查

### 4.1 账号备忘（`Modules/Vault`、`Core/VaultCrypto`）

- [ ] 加密行落盘无明文；未勾选加密的行明文落盘（产品如此）
- [ ] 勾选加密立刻封存 Enc、界面掩码；空 Enc 时不覆盖内存明文
- [ ] 复制 / 复制全部 / 导出：加密行须已验证
- [ ] 导入按导出格式**追加**，不覆盖整篇；导入行默认不加密
- [ ] 「复制新增当前行」只带平台和 URL，账号密码空、不勾选加密
- [ ] 行内删除需再点「确认删除」；忘记查看密码无法解密（无后门、密钥不落盘）

### 4.2 剪贴板（`ClipboardImage`、`ClipboardHistory`）

- [ ] 禁止把缩略图当原图写回；原图 PNG 缺失或损坏则提示失败，不用缩略图代替；DataObject 含 PNG 与 24 位 DIB；全 0 Alpha 补不透明
- [ ] 账号备忘复制默认不写入剪贴板历史
- [ ] 「记录剪切图片」在剪贴板工具顶栏，默认关；关时不解码入库；设置勾选「藏托盘期间不把剪贴板图片记入历史」时停泊态不解码图片
- [ ] 图片张数单独上限（默认 20，最多 50，不超过总条数）；下调只丢未固定旧图；写回仍是原图
- [ ] 列表行之间有分割线（剪贴板历史、窗口置顶）
- [ ] 空白或纯空白文本不入库；相同文本/图片去重，以最后一次为准
- [ ] 剪贴板占用：中文提示，不弹全局异常、不插入半截文本
- [ ] 查看图片：按屏幕像素 1:1，完整落入窗口（超出只缩小），无横竖滚动条；尺寸用 `PixelsPerInch`（约 96/144），禁止误用 `PixelsPerDip`；文本查看仍可靠顶部滚动

### 4.3 笔记 / 待办

- [ ] 未保存离开确认；自动保存开时关抽屉 flush；锁定时即使勾了自动保存也不 flush
- [ ] 笔记类型筛选与新增下拉仍对；目录树可展开；笔记可移动；待办提醒/导出关窗不泄漏资源
- [ ] Markdown/笔记预览：Win10/11 有 `WebView2Runtime` 时标题「预览（Edge）」且不重解压；只有 CAB 时首次真正打开预览才询问/解压，设置可选 IE。Win7 用 IE（正路径，无降级条、不询问）。用户选 IE 不记故障；缺内核、解压或启动失败才提示并退 IE/纯文本 + `CompatDegrade`/`AppLog`。笔记只编辑不触发。不改数据根与 `%LOCALAPPDATA%\IntraBox\WebView2`。切走 `Release`，不得只 `Navigate` 留文档；页内 `#锚点` 滚动不冲空白，http(s) 不离开预览
- [ ] 示例可删，启动时不要把用户改过的示例盖回去（除非产品规定刷新示例）
- [ ] 待办 / 笔记 / 账号备忘可勾选锁定，锁定后只能查看，不能编辑或删除
- [ ] 待办提醒窗未手动关闭时约 1 分钟自动关（`TodoRemindRepeat.AutoCloseSec`）；自动关不算稍后、不静音。点 × / 稍后仍按间隔再弹；最后一次关掉后当天不再弹
- [ ] 待办「仅工作日」走 `WorkdayHelper`（法定假不弹、调休上班会弹），与「工作日历」同一套表
- [ ] 待办详情模板为加粗「【任务标题】: / 【任务来源】: / 【任务描述】:」；破坏格式保存会确认；自动保存不在损坏时静默写入；托盘静默卸载走 `FlushSilent`，不得 `FlushNow` / `ConfirmHelper`
- [ ] 账号备忘托盘静默卸载：冲盘失败不 `MessageBox`；点保存 / 关抽屉 / `FlushNow` 仍弹；先冲盘再 `VaultStore.Flush` 再 `ForgetSession`

### 4.4 设置 / 数据目录 / 主题
