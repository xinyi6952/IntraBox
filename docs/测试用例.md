# IntraBox 测试用例文档

本文档说明 IntraBox 的测试方式：**确定性逻辑用自动化测试（`test.bat` 一键跑），交互型功能按手动清单逐项验证。**

## 一、自动化测试（已实现，跑 `test.bat`）

`test.bat` 会构建测试项目 `tests/IntraBox.Tests` 并运行全部 MSTest 用例。当前已覆盖以下确定性逻辑：

| 功能 | 覆盖的用例 | 关键断言 |
|---|---|---|
| JSON 格式化 | 美化/压缩/非法/空输入 | 缩进换行、单行无空格、错误返回 null+信息 |
| SQL 格式化 | 关键字大写/子句换行/AND 行首 | 含 SELECT、FROM、缩进 |
| 哈希 | MD5/SHA256/差异/ToHex | RFC 官方向量（如 MD5("abc")） |
| Base64 | 编码/往返/非法 | 已知值、往返一致、抛异常 |
| 时间戳 | 起点/往返/秒毫秒 | 时间戳 0 = 1970、往返一致 |
| ULID | 长度/字符集/两次不同 | 26 位 Crockford Base32 |
| 模块注册 | 无独立 ULID/GIF 入口 | 仅 generator，无 ulidgen、screengif |
| 文本文件编码 | GBK/UTF-8/带 BOM 往返 | 自动检测编码、写回字节一致 |
| Hosts 文件 | 保存/注释空行/启用切换/改动摘要 | 保留注释空行、未改行原样写回 |
| 防止睡眠 | 时长解析 | 分钟/小时换算、非法输入报错 |
| 文件整理 | 匹配/目录展开/日期去重 | 扩展名忽略大小写、{date} 不与当天重复 |
| 设置历史 | 数字兼容/剪贴板条数夹取 | long/double 兼容、超长字符串不入库 |
| 命名转换 | 分词/各风格/空输入 | camelCase/snake_case、XMLHttp 拆分 |
| URL 解析 | 各字段/query 解码/hash/非法 | scheme/host/port/path、%E4%BD%A0→你好 |
| Unicode 检查 | ASCII/中文/代理对/编码 | U+0041、U+4E2D、😀=U+1F600、UTF-8/16 |
| Semver 比较 | 解析/比较/^~范围 | 预发布<正式版、^1.2.3<2.0.0 |
| JSON Schema | 推断/校验/错误 | type/properties/required、缺必填报错 |
| 正则解释 | 转义/锚点/字符类/量词/分组 | \d=数字、[abc]=集合、{2,3}=重复 |
| 编解码 | URL/HTML/Unicode 编解码 | 百分号编码、HTML 实体、\u 转义往返 |
| 行处理 | 拆行/去重/排序/自然序/前后缀 | file2<file10、保序去重 |
| 文本统计 | 字符/词/行/段落/词频 | 忽略大小写词频、空行分段 |
| TXT 转 Excel | 分隔符探测/表格解析 | 逗号/制表符、空行跳过、单元格 trim |
| 加解密 | AES/DES 往返、RSA、密钥派生 | 加密解密往返、密文含随机 IV |
| 证书解码 | PEM 解析/格式化 | CN=主体、有效期、指纹 |
| JSON 转类 | 标识符清洗/类型推断 | C#/Java 模型、数组列表 |

> 确定性逻辑已全部抽出 `Core/*Helper` 并通过 MSTest 用例；仅「进制类转换」在代码中无独立实现而未单独覆盖。

## 二、手动测试清单（交互型功能，需人工点）

以下功能依赖 UI/系统交互，无法自动化，按「操作 → 期望」逐项验证。

### 截图 / 屏幕标尺
- [ ] 全局热键（Ctrl+Alt+A）能唤起，出现全屏遮罩 + 十字光标
- [ ] 框选区域 → 显示工具栏（默认是「移动/选择」光标，非矩形）
- [ ] 画矩形/箭头/文字/马赛克 → 撤销 → 重做（重做能恢复）
- [ ] 钉在桌面后，工具栏仍显示、仍可标注
- [ ] 保存到文件、复制到剪贴板
- [ ] OCR 识别图中文字，结果可选中复制
- [ ] 屏幕标尺：热键或按钮打开 → H/V/R 测量 → 显示像素与厘米

### 文本比对
- [ ] 粘贴左右文本 → 自动出差异（红删绿增）
- [ ] 点合并箭头 → 合并 → 撤销（Ctrl+Z）
- [ ] 上一个/下一个差异 → 到顶/到底时提示不循环
- [ ] 拖文件到左右 → 自动加载并比对；GBK/UTF-8 文件不乱码
- [ ] 文件比对 + 合并后点清空 → 弹保存确认

### 剪贴板历史
- [ ] 复制文字 → 出现在列表 → 双击写回
- [ ] 搜索、固定、右键「查看」（窗口内最大化）/「删除」
- [ ] 时间显示 yyyy-MM-dd HH:mm:ss
- [ ] 不打开剪贴板工具时复制 → 打开后能看到；退到托盘再复制 → 回来仍能看到
- [ ] 切到其它工具期间复制，再回到剪贴板历史能看到
- [ ] 写回剪贴板后列表不立刻多出一条重复记录
- [ ] 复制多张截图后列表仍有缩略图；界面提示「仅保留缩略图」；写回的是缩略图
- [ ] 反复切换截图/比对/格式化等工具后，任务管理器内存能回落、不持续攀升

### 文件整理 / 文件查找 / 批量重命名 / 重复文件
- [ ] 文件整理：选目录 → 规则 → 预览目录结构 → 执行 → 撤销
- [ ] 规则条件选「早于指定日期」时，条件值是日期选择器而不是普通文本框
- [ ] 文件查找：关键字 → 结果列表 → 「定位到文件夹」
- [ ] 批量重命名：规则 → 预览 → 执行 → 撤销
- [ ] 重复文件查找：选目录 → 按哈希分组 → 定位/删除

### 端口 / 文件占用 / Hosts / 注册表
- [ ] 端口占用：列出端口→进程映射 → 结束进程
- [ ] 文件占用：选文件 → 列出占用进程 → 结束进程
- [ ] 端口占用、文件占用界面顶部有黄色权限/风险提醒
- [ ] Hosts：增删改映射 → 保存生效；表头在深色/浅色主题下都清晰
- [ ] Hosts、注册表界面顶部有黄色权限/策略提醒
- [ ] 注册表：只读浏览、能复制路径

### 取色器 / 色盲模拟
- [ ] 屏幕取色 → HEX/RGB/HSL 正确 → 左键确定
- [ ] 色盲模拟：选图 → 各色盲视角预览

### 窗口置顶 / 防止睡眠
- [ ] 窗口置顶：选窗口 → 置顶/取消
- [ ] 防止睡眠：开启后系统不自动睡眠
- [ ] 防止睡眠界面顶部有红色合规提醒（勿对抗管理员强制睡眠）

### 图片 / 二维码
- [ ] 图片：批量压缩/缩放/格式转换 → 输出正确
- [ ] 二维码：文本生成二维码 → 保存 PNG

### UUID / ULID / 密码
- [ ] 导航只有「UUID/ULID/密码生成」一处入口，无独立 ULID 工具
- [ ] 可切换 UUID v4 / ULID 并批量生成、复制

### Markdown 预览 / 正则可视化
- [ ] Markdown：输入 → 实时预览渲染
- [ ] 预览标题栏对角箭头可窗口内最大化/还原，按钮不被预览挡住
- [ ] 正则可视化：输入正则 → 显示中文结构解释 + 语法高亮

### 本机信息 / 证书解码 / JSON Schema / Semver / Unicode 检查
- [ ] 本机信息：显示 IP/MAC/主机名/系统版本，可复制；Win11 正确显示「Windows 11」
- [ ] 证书解码：选证书文件 → 解析主体/有效期/指纹
- [ ] JSON Schema：Schema 校验 / 从 JSON 反推 Schema
- [ ] Semver：版本号比较、范围判断
- [ ] Unicode 检查：码点/UTF-8/UTF-16/HTML 实体显示

### 启动 / 设置
- [ ] 首次运行弹出欢迎引导，关闭后不再出现；设置里可再次打开
- [ ] 打开某工具后退出再启动，自动回到该工具
- [ ] 工具输入重启后仍在（history.json）
- [ ] 设置里剪贴板条数默认 20，可调 1–200，立即生效且固定项不被误删
- [ ] 主题深色/浅色/跟随系统切换立即生效

## 三、测试节奏建议

1. **日常开发完**：跑 `test.bat`（自动化）+ 只手动测本次改动的模块。
2. **发版前**：跑 `test.bat` + 按上面清单全量过一遍（约半小时）。
