IntraBox —— 内网效率聚合工具
========================================
项目地址（主仓库）：https://gitee.com/xinyi6952/IntraBox
镜像（GitHub）：https://github.com/xinyi6952/IntraBox
开发者：shuyuesheng

一、产品简介
面向内网工作者与开发者的绿色免安装聚合效率工具。
纯本地运行、无网络依赖、无遥测、无自动更新，数据不出本机。
当前程序版本见窗口标题、设置页右下角或托盘图标悬停（四段，如 1.0.0.312），与右键 IntraBox.exe → 属性 → 详细信息相同。点击设置里的版本号可复制。

二、系统要求与检查

1. 操作系统
   - Windows 7 SP1 及以上（Windows 10 / 11 均满足）

2. .NET Framework 4.8
   - Windows 10 1903 及以上：系统已预装，无需额外安装
   - Windows 7：需自行安装 .NET Framework 4.8 运行时

   【如何检查是否已具备】（任选其一）
   · 最省事：直接双击 IntraBox.exe，能打开主窗口即已具备；若弹出
     「此应用程序需要 .NET Framework 4.8，是否现在安装」的系统提示，即缺失。
   · 命令行查询（在 cmd 中执行）：
       reg query "HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full" /v Release
     返回的 Release 值 ≥ 528040（十六进制 0x80EA8）即已具备 4.8。

   【缺失时如何安装】
   · 到微软官网下载「.NET Framework 4.8 离线安装包」
     （文件名 ndp48-x86-x64-allos-enu.exe，约 115MB），拷到目标机器双击安装即可，全程无需联网。
     官方下载页：https://dotnet.microsoft.com/download/dotnet-framework/net48

3. 截图 OCR 的额外依赖（可选）
   - OCR 识别功能依赖 Visual C++ 2015-2019 运行库（x64）。本程序是 64 位，只装 x86 不够。
   - 未安装时，截图、标注、保存、复制均不受影响，仅「OCR 识别文字」会失败，弹窗会说明原因；详情在 %LOCALAPPDATA%\IntraBox\logs。
   - 到微软官网下载 VC++ 运行库（x64 约 24MB）：
       https://aka.ms/vs/17/release/vc_redist.x64.exe
     Win7 若还缺其它 32 位组件可另装 x86（约 13MB）：https://aka.ms/vs/17/release/vc_redist.x86.exe
     Win10 / Win11 通常已预装 x64 运行库，一般无需安装。

4. Windows 7 安装 .NET Framework 4.8 的潜在前置更新（仅老 Win7 需注意）
   - 若 Win7 机器很旧（未打过 2019 年之后的补丁），装 .NET Framework 4.8 可能失败，
     需先安装 SHA-2 代码签名支持更新 KB4474419 与 Servicing Stack Update KB4490628。
   - 已打过补丁的 Win7 可直接装 4.8，无需额外处理。

5. Markdown / 笔记预览
   - Windows 10 / 11：预览可以用随包 Edge。安装包里是 WebView2Runtime.cab（压缩包），第一次真正打开预览时才会问要不要解压到本文件夹的 WebView2Runtime（大约 670 MB，只解压一次，压缩包仍保留）。解压时会显示「正在解压 Edge 预览组件，大约需要数分钟，只此一次」，可以取消；取消后这次预览用 IE，不会把设置改成永久不解压。已经解压过的直接用，不用本机 Edge。
   - 设置 →「Markdown / 笔记预览」可选：打开预览时再问 / 使用随包 Edge（首次解压）/ 使用 IE，不解压。选 IE 不占这部分空间。笔记只编辑、不打开预览时不会解压。
   - Windows 7：使用 IE（正路径，不是降级），不询问、不解压。未装 IE11 时表格样式可能较差。
   - 解压失败、磁盘空间不够，或内核无法启动时，预览区会提示并改用 IE。详情在 %LOCALAPPDATA%\IntraBox\logs。编辑、保存、待办和笔记数据不受影响。换电脑时把整个文件夹一起复制即可，不必重新解压。

三、使用方法（绿色免安装）
1. 将本文件夹解压/复制到任意位置，无需安装
2. 双击 IntraBox.exe 启动
3. 启动后显示主窗口，同时驻留系统托盘
4. 关闭主窗口会询问：最小化到托盘，或退出进程（可勾选「不再提醒」）；选托盘后窗口先隐藏，不立刻清空内存。默认约 90 秒后才把空闲物理内存还给系统（任务管理器「内存」下降，专用内存如网页控件提交量往往几乎不变），若当前工具没有未保存内容会卸掉以进一步省内存。再打开时菜单先亮、右侧显示「正在打开…」，再恢复上次工具。左侧菜单鼠标经过会高亮；每行星标点一下即收藏（黄色★，不切换工具，重启仍在）。点击后该项立刻选中，连续点击只打开最后一次。开了自动保存的待办/账号备忘会先静默冲盘（待办损坏模板不弹窗、不写盘；账号备忘落盘失败不弹框）。托盘图标右键「退出」才走退出确认并真正结束。设置里可「关闭时再次询问」，并可改空闲秒数、工作集高水位（80–2048 MB，默认 220）与低水位（默认 120，上限随高水位 −20）、是否启动恢复上次工具、托盘里是否不记剪贴板图片。目录大小分析、文件查找等耗时任务进行中切到其它工具会二次确认，确认后才取消任务并切换
5. 窗口右下角「内存 n MB」为工作集（物理内存/任务管理器口径）；点击可查看明细（数字旁「?」悬停有口径说明）并手动回收。专用内存是提交量、可换出，不等于一直占着那么多物理 RAM；回收主要降低工作集，随后用到还会涨

四、已内置功能（共 49 个）

表单必填项标签前有红色 *，校验失败与拦截提示为红字。

五、数据与安全
- 配置与历史默认在 %LOCALAPPDATA%\IntraBox\Data（config.json、launcher.json、gc.log 等），不写系统注册表。可在设置中更改数据目录。换免安装包只需覆盖程序文件夹。`gc.log` 记录 IntraBox 强制回收（原因、耗时、内存前后），超过 1MB 自动截尾；不记录 .NET 自己的后台 GC
- 无任何网络请求

  .NET Framework 4.8 离线安装包（约 115MB）
      https://dotnet.microsoft.com/download/dotnet-framework/net48
  VC++ 2015-2019 运行库 64 位（约 24MB，截图 OCR 必须）
      https://aka.ms/vs/17/release/vc_redist.x64.exe
  VC++ 2015-2019 运行库 32 位（约 13MB，可选）
      https://aka.ms/vs/17/release/vc_redist.x86.exe
  HTTPS（任务编排 REST/SOAP、导入 WSDL）：Win7 还需系统 TLS 1.2 补丁（如 KB3140245）。
  程序在 Win10/11 打开 TLS 1.2 与 1.3，Win7 只开到 1.2；系统未打补丁时访问 https 可能失败。
  Markdown / 笔记预览：Win10/11 可在第一次打开预览时把 WebView2Runtime.cab 解压成 Edge；也可在设置里改用 IE。Win7 用 IE。未装 IE11 时表格样式可能较差。
  失败原因写在预览区提示，并记入 %LOCALAPPDATA%\IntraBox\logs。
